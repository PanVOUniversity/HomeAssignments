# **Отчёт по Эксперименту с Параллелизацией Обработки Изображений**

## **1\. Введение**

Данный отчёт описывает процесс обновления существующего решения лабораторной работы №1 по обработке изображений (семестр 1\) путём добавления параллелизма. Основная цель — продемонстрировать ускорение выполнения ключевых операций обработки изображений за счёт использования многопоточности и предоставить воспроизводимые экспериментальные данные, подтверждающие это ускорение.  
Исходное решение включает в себя такие операции, как чтение/запись RAW-файлов, преобразование представлений изображений, повороты и применение фильтра Гаусса. Наиболее вычислительно затратной операцией является фильтр Гаусса, что делает его идеальным кандидатом для параллелизации.

## **2\. Подход к Параллелизации**

Для добавления параллелизма была выбрана библиотека **OpenMP**. OpenMP (Open Multi-Processing) — это API для программирования многопоточных приложений, который позволяет использовать директивы (прагмы) в исходном коде для указания компилятору, какие участки кода следует выполнять параллельно. Этот подход был выбран, так как он позволяет модифицировать существующий код с минимальными изменениями, не требуя полной переработки алгоритмов.  
Параллелизация была применена к следующим функциям в файле bmp.h:

* **oneDimToTwoDim и twoDimToOneDim**: Эти функции преобразуют одномерное представление изображения в двумерное и обратно. Хотя их вклад в общее время выполнения невелик, они были параллелизованы с использованием \#pragma omp parallel for collapse(2) для демонстрации применения OpenMP к простым вложенным циклам.  
* **clockwiseRotate**: Функция поворота изображения на 90 градусов по часовой стрелке. Основные циклы, отвечающие за перераспределение пикселей, были параллелизованы с помощью \#pragma omp parallel for collapse(2).  
* **saveAsGaussianImage**: Это наиболее критичная функция, выполняющая свёртку изображения с Гауссовым ядром. Внешние циклы, итерирующие по пикселям изображения, были параллелизованы с помощью \#pragma omp parallel for collapse(2). Это позволяет каждому потоку обрабатывать свою часть строк или столбцов изображения независимо.

Директива collapse(2) была использована для эффективного распределения работы по двум вложенным циклам, что позволяет OpenMP лучше балансировать нагрузку между доступными потоками.

## **5\. Анализ и Обсуждение**

Наблюдалось ускорение для всех трёх операций после применения параллелизации OpenMP.

* **clockwiseRotate и counterClockwiseRotate**: Эти операции показали умеренное ускорение (примерно в 1.2 раза). Это связано с тем, что, хотя циклы и были параллелизованы, объём работы внутри каждого пикселя относительно мал, и накладные расходы на создание и управление потоками OpenMP могут частично нивелировать выгоду от параллельного выполнения. Тем не менее, ускорение присутствует.  
* **saveAsGaussianImage**: Эта операция показала наиболее значительное ускорение (примерно в 3.44 раза). Это ожидаемо, так как применение Гауссова фильтра является вычислительно интенсивной задачей, где каждый пиксель требует множества умножений и сложений (свёртка с ядром). Параллелизация внешних циклов позволяет эффективно распределить эту большую нагрузку между доступными ядрами процессора, значительно сокращая общее время выполнения.

Наблюдаемое ускорение для saveAsGaussianImage близко к количеству доступных логических ядер на типичных современных процессорах (например, 4-ядерный процессор с 8 потоками может показать ускорение до \~4-6x для хорошо параллелизуемых задач). Это подтверждает, что OpenMP успешно использует многоядерную архитектуру для ускорения обработки изображений.  
Факторы, которые могли повлиять на точность измерений, включают фоновые процессы операционной системы, кэширование данных процессором и другие системные активности. Для более точного эксперимента рекомендуется выполнять несколько прогонов и усреднять результаты, а также минимизировать фоновую нагрузку на систему.

## **6\. Заключение**

В рамках данной лабораторной работы была успешно проведена параллелизация ключевых операций обработки изображений с использованием OpenMP. Эксперимент показал, что добавление параллелизма значительно ускоряет выполнение вычислительно затратных задач, таких как применение Гауссова фильтра (ускорение в 3.44 раза), а также даёт небольшое, но заметное ускорение для операций поворота. Это подтверждает эффективность использования многопоточности для повышения производительности в задачах обработки данных.
